# Week 02: Python Language Basics

Welcome to Week 02 of ACU-ITEC102. This week introduces the core building blocks of the Python programming language: code semantics and indentation rules, scalar data types, arithmetic and logical operators, conditional branching, iteration loops, and string handling.

---

## Learning Outcomes
By completing this week's materials, you will be able to:
1. **Master Python Semantics & Readability**: Apply PEP 8 formatting conventions, use whitespace indentation for code blocks, and write meaningful code comments.
2. **Manipulate Scalar Data Types**: Work with integers, floating-point numbers, booleans, and strings, performing both implicit and explicit type conversions (`casting`).
3. **Evaluate Expressions with Operators**: Apply arithmetic, comparison, and logical operators to build algorithmic decision logic.
4. **Control Program Flow with Conditionals**: Implement decision trees using `if`, `elif`, and `else` control structures.
5. **Automate Iteration with Loops**: Construct `for` loops with `range()` and `while` loops with `break` and `continue` statements.
6. **Perform String Operations**: Slice strings, format output using modern f-strings, and utilise common escape sequences.
