# Week 02: Introduction to Python Basics

This folder contains the teaching materials for Week 02, covering fundamental Python concepts such as semantics, types, conditionals, operators, loops, and strings.

## Directory Structure

We provide isolated modules covering each topic:
- `01.PythonSemantics/`
- `02.ScalarTypes/`
- `03.Operators/`
- `04.Conditionals/`
- `05.Loops/`
- `06.StringHandling/`

Each folder contains a `Jupyter Notebook` (`.ipynb`), structured markdown documentation, and a dedicated `Makefile` to quickly launch the environment.

## Python Source Scripts (`src/`)

For those who prefer working with standard Python scripts over interactive notebooks, we provide `src/` where the core concepts and snippets from the notebooks are converted into standalone executable scripts:

1. `src/01_python_semantics.py` - Explains indentation, comments, and variable assignments.
2. `src/02_scalar_types.py` - Showcases `int`, `float`, and explicit/implicit type conversions.
3. `src/03_operators.py` - Demonstrates arithmetic, modulus, and logical comparisons.
4. `src/04_conditionals.py` - Examples of `if`, `elif`, and `else` control flow.
5. `src/05_loops.py` - Iteration examples using `for` loops, `while` loops, and `break` statements.
6. `src/06_string_handling.py` - String slicing and formatting examples.

You can execute any of these scripts directly from your terminal using Python 3, e.g.:
```bash
python3 src/01_python_semantics.py
```
