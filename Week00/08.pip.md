# Running Projects with `pip` and `python`

If you prefer not to use `uv` or are working in an environment where it's not available, you can use the standard `pip` (or `pip3`) and `python` (or `python3`) commands to run your scripts.

## Step 1: Install Dependencies

First, you need to manually install any libraries your script requires using `pip3 install`. 

### Example

```bash
# 1. Navigate to the project's source directory
cd ACU-ITEC102/Week06/01.Introduction_and_Series/src

# 2. Install required packages (e.g., pandas and numpy)
pip3 install pandas numpy
```

## Step 2: Run the Script

Once the dependencies are installed, you can execute the script using the `python3` command.

### Example

```bash
# Run the Python script
python3 IntroductionandSeries.py
```

> **Note:** It is generally recommended to use a virtual environment (`venv`) when installing packages with `pip` to avoid conflicting dependencies across different projects.
