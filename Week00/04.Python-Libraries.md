# Managing Python Libraries

In this course we use: **pandas**, **numpy**, **matplotlib**, **seaborn**, and **scikit-learn**.

---

## a) Installing Libraries with `pip`

`pip` is Python's built-in package manager.

```bash
# Activate your virtual environment first (see 03.Python-venv.md)
pip install pandas numpy matplotlib seaborn scikit-learn
```

Upgrade a package:

```bash
pip install --upgrade pandas
```

List installed packages:

```bash
pip list
```

---

## b) Installing Libraries with `uv` (Recommended)

> **Note:** `uv` is a fast, modern alternative to `pip` written in Rust. It is significantly faster and handles dependency resolution more reliably. We recommend using `uv` for this course.

### Install `uv`

```bash
# macOS / Linux
curl -Lsf https://astral.sh/uv/install.sh | sh

# Windows
powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### Use `uv` to install packages

```bash
uv pip install pandas numpy matplotlib seaborn scikit-learn
```

### Create a project with `uv`

```bash
uv init my-project
cd my-project
uv add pandas numpy matplotlib seaborn scikit-learn
```

## Dependency Management

### `requirements.txt`

A plain text file listing your project's dependencies — used with `pip`.

**Generate from current environment:**

```bash
pip freeze > requirements.txt
```

**Install from file:**

```bash
pip install -r requirements.txt
```

Example `requirements.txt`:

```
pandas>=2.0
numpy>=2.0
matplotlib>=3.8
seaborn>=0.13
scikit-learn>=1.5
```

---

### `pyproject.toml`

The modern standard for Python project metadata and dependencies — used with `uv` and other modern tools.

Example `pyproject.toml`:

```toml
[project]
name = "my-project"
version = "0.1.0"
requires-python = ">=3.14"
dependencies = [
    "pandas>=2.0",
    "numpy>=2.0",
    "matplotlib>=3.8",
    "seaborn>=0.13",
    "scikit-learn>=1.5",
]
```

Install all dependencies defined in `pyproject.toml`:

```bash
uv sync
```
