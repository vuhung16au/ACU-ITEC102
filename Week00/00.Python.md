# Installing Python and Setting Up a Development Environment

We use and recommend **Python 3.14** for this course.

---

## Windows

1. Download the installer from [python.org/downloads](https://www.python.org/downloads/).
2. Run the installer. **Check "Add Python to PATH"** before clicking Install.
3. Open Command Prompt and verify:

```cmd
python --version
```

## macOS

Use [Homebrew](https://brew.sh/) (recommended):

```bash
brew install python@3.14
```

Or download the macOS installer from [python.org/downloads](https://www.python.org/downloads/).

Verify:

```bash
python3 --version
```

## Linux (Debian/Ubuntu)

```bash
sudo apt update
sudo apt install python3.14 python3.14-venv python3.14-dev -y
```

Verify:

```bash
python3 --version
```

---

## Verification

Run the following to confirm Python is installed and working:

```bash
python3 --version
# Expected: Python 3.14.x

python3 -c "print('Hello, Python!')"
# Expected: Hello, Python!
```

If you see the version number and the greeting, your Python installation is successful.
