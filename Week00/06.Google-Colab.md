# Google Colab for Python Development

Google Colab is a free, cloud-based Jupyter Notebook environment that requires no local setup.

Access it at: [colab.research.google.com](https://colab.research.google.com/)

---

## Getting Started with Colab

1. Go to [colab.research.google.com](https://colab.research.google.com/).
2. Sign in with a Google account.
3. Click **New Notebook** or open an existing `.ipynb` file from Google Drive or GitHub.
4. Write and run Python code in cells — Colab provides a free GPU/TPU-accelerated runtime.

Common libraries (pandas, numpy, matplotlib, seaborn, scikit-learn) are **pre-installed** in Colab.

## Recommended Workflow: GitHub + Colab

We recommend storing your Jupyter Notebooks in a **GitHub private repository** for version control and collaboration, and opening them in Colab for execution.

### Why this approach?

- **Version control**: Track changes to your notebooks using Git.
- **Collaboration**: Share notebooks with teammates via GitHub.
- **Free compute**: Use Colab's cloud runtime without running anything locally.
- **Private**: Keep your work private in a private repository.

### How to open a GitHub notebook in Colab

1. Push your `.ipynb` notebook to a GitHub repository (private or public).
2. Go to [colab.research.google.com](https://colab.research.google.com/).
3. Click **File → Open notebook → GitHub**.
4. Paste the repository URL or search for the notebook.
5. Click the notebook to open it in Colab.

To save changes back to GitHub from Colab:

```
File → Save a copy in GitHub
```

## Verification

1. Open [colab.research.google.com](https://colab.research.google.com/) and create a new notebook.
2. Run the following cell:

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import sklearn

print("pandas:", pd.__version__)
print("numpy:", np.__version__)
print("scikit-learn:", sklearn.__version__)
print("Google Colab is working correctly!")
```

Expected output:

```
pandas: 2.x.x
numpy: 2.x.x
scikit-learn: 1.x.x
Google Colab is working correctly!
```

If all libraries import successfully and you see the version numbers, your Colab environment is ready.
