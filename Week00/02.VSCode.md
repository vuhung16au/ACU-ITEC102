# Installing VS Code and Setting Up a Development Environment

---

## 1. Install VS Code

Download and install from [code.visualstudio.com](https://code.visualstudio.com/).

Available for **Windows**, **macOS**, and **Linux**.

---

## 2. Install the Python Extension

1. Open VS Code.
2. Press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS) to open the Extensions panel.
3. Search for **Python** (by Microsoft) and click **Install**.

This extension provides IntelliSense, linting, debugging, and virtual environment support.

---

## 3. Install Jupyter Notebook and JupyterLab Extensions

In the Extensions panel, install:

- **Jupyter** (by Microsoft) — runs `.ipynb` notebooks inside VS Code
- **Jupyter Keymap** (optional) — classic Jupyter keyboard shortcuts

After installation, open any `.ipynb` file to launch the notebook interface inside VS Code.

To create a new notebook:

```
Ctrl+Shift+P → "Create: New Jupyter Notebook"
```

---

## 4. Install the Git Extension

Git support is **built into VS Code** — no separate extension is required.

To use it:

- Click the **Source Control** icon in the Activity Bar (or press `Ctrl+Shift+G`).
- VS Code will detect your Git repository automatically.

Useful optional extension: **GitLens** — adds enhanced blame, history, and diff views.

---

## 5. Select a Python Interpreter

After installing the Python extension:

1. Press `Ctrl+Shift+P` → type **"Python: Select Interpreter"**.
2. Choose the Python 3.14 interpreter (or your virtual environment).

---

## Verification

1. Open VS Code and create a new file `test.py`:

```python
print("VS Code + Python is working!")
```

2. Press `F5` or right-click → **Run Python File**. You should see the output in the terminal.

3. Create a new Jupyter Notebook, add a cell with `1 + 1`, and run it. The output should be `2`.

4. Open the Source Control panel — if your folder is a Git repository, you should see file changes listed.
