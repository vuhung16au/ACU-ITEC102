# Running Projects with `uv`

`uv` is an extremely fast Python package and project manager. It simplifies running scripts with dependencies by automatically managing virtual environments for you.

## Running a Script with `uv`

You can use the `uv run` command to execute a Python file. When you do this, `uv` will automatically look for a `pyproject.toml` file in your project directory, install the required dependencies, and then run the script.

### Example

```bash
# 1. Navigate to the project's source directory
cd ACU-ITEC102/Week06/01.Introduction_and_Series/src

# 2. Run the Python script using uv
uv run IntroductionandSeries.py
```

That's it! `uv` handles the rest, ensuring your script runs in an isolated environment with all the correct packages installed.
