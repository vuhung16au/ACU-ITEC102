# Docker for Python Development

Docker lets you package and run applications in isolated containers — ensuring consistency across Windows, macOS, and Linux.

---

## 1. Install Docker

Download and install **Docker Desktop** from [docker.com/get-started](https://www.docker.com/get-started/).

Available for **Windows**, **macOS**, and **Linux**.

After installation, verify Docker is running:

```bash
docker --version
docker compose version
```

---

## a) Docker + Python with `docker-compose`

### Project structure

```
my-python-app/
├── app.py
├── requirements.txt
└── docker-compose.yml
```

### `app.py`

```python
import pandas as pd
import numpy as np

data = pd.DataFrame({"x": np.arange(5), "y": np.arange(5) ** 2})
print(data)
```

### `requirements.txt`

```
pandas
numpy
```

### `docker-compose.yml`

```yaml
services:
  app:
    image: python:3.14-slim
    working_dir: /app
    volumes:
      - .:/app
    command: >
      sh -c "pip install -r requirements.txt && python app.py"
```

### Deploy and run

```bash
docker compose up
```

Docker will pull the Python image, install dependencies, and run your script. To stop, press `Ctrl+C`.

## b) Docker + Jupyter Notebook with `docker-compose`

### Project structure

```
my-jupyter/
├── notebooks/
└── docker-compose.yml
```

### `docker-compose.yml`

```yaml
services:
  jupyter:
    image: jupyter/scipy-notebook:python-3.11
    ports:
      - "8888:8888"
    volumes:
      - ./notebooks:/home/jovyan/work
    environment:
      - JUPYTER_ENABLE_LAB=yes
```

> **Note:** The `jupyter/scipy-notebook` image comes with pandas, numpy, matplotlib, seaborn, and scikit-learn pre-installed.

### Deploy and run

```bash
docker compose up
```

Open your browser at `http://localhost:8888`. Copy the token from the terminal output when prompted.

Your notebooks are saved to the `./notebooks` folder on your host machine.

To stop:

```bash
docker compose down
```

## Verification

### Python app

After running `docker compose up` for the Python app, you should see a printed DataFrame in the terminal.

### Jupyter Notebook

After running `docker compose up` for Jupyter, open `http://localhost:8888` in your browser. Create a new notebook and run:

```python
import pandas as pd
print(pd.__version__)
```

You should see the pandas version printed.
