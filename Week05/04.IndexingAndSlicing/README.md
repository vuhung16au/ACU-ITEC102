# Indexing and Slicing Arrays (1D and 2D)

This folder covers Indexing and Slicing Arrays (1D and 2D). It is part of the Week 05 curriculum for introductory NumPy.

## Structure
- `QUICKSTART.md`: Guide to setting up the environment.
- `docs/`: Concept explanations.
- `notebooks/`: Interactive demonstrations and exercises.
- `src/`: Standard Python script equivalents of the concepts.
