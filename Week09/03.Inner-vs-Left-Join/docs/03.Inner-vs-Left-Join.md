# Inner vs Left Join in Pandas

Join mechanics dictate which observations survive a merge between two relational tables.

---

## Join Mechanics

```text
       Left Table (Students)                  Right Table (Scholarships)
     +-------------------------+              +---------------------------+
     | StudentID | Name        |              | StudentID | Scholarship   |
     |-----------|-------------|              |-----------|---------------|
     |    101    | Liam Nguyen |              |    102    | VC Award      |
     |    102    | Emma Watson | <---MATCH--> |    104    | STEM Award    |
     |    103    | Oliver Brown|              |    106    | Alumni Grant  |
     |    104    | Sophia Vu   | <---MATCH--> +---------------------------+
     |    105    | Noah Taylor |
     +-------------------------+
```

### Inner Join (`how='inner'`)
Only matches are kept:
- Returns StudentID: `102`, `104`.
- Silently deletes students `101`, `103`, `105` and scholarship `106`.

### Left Join (`how='left'`)
All rows from the left table are kept:
- Returns StudentID: `101`, `102`, `103`, `104`, `105`.
- Fills missing scholarship info for `101`, `103`, `105` with `NaN`.

---

## Summary Rule of Thumb
- Use **Inner Join** when you only care about entities that have active relationships in both tables (e.g. sales that have corresponding shipments).
- Use **Left Join** when reporting on a master population (e.g. all enrolled students, all active customers) so non-purchasers or non-awardees are still accounted for.
