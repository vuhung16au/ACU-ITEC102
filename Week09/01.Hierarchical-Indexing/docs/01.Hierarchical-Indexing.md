# Hierarchical Indexing (MultiIndex) in Pandas

A `MultiIndex` allows representing multi-dimensional datasets within standard two-dimensional Pandas DataFrames.

---

## Key Operations

### 1. MultiIndex Creation
```python
import pandas as pd

states = ["NSW", "NSW", "VIC", "VIC"]
cities = ["Sydney", "Newcastle", "Melbourne", "Geelong"]

idx = pd.MultiIndex.from_arrays([states, cities], names=["State", "City"])
df = pd.DataFrame({"Sales": [850, 320, 780, 290]}, index=idx)
```

### 2. Slicing Levels
- **Outer Level**: `df.loc['NSW']`
- **Tuple Slicing**: `df.loc[('NSW', 'Sydney')]`
- **Inner Level Direct Access (Cross-Section)**:
  ```python
  # Access inner level 'City' directly
  df.xs("Sydney", level="City")
```

### 3. Level-Based Aggregations
Compute summary statistics at any level:
```python
df.groupby(level="State").sum()
```

### 4. Moving Between Flat and MultiIndex
```python
# Convert to flat table
flat = df.reset_index()

# Re-convert to MultiIndex
hierarchical = flat.set_index(["State", "City"])
```
