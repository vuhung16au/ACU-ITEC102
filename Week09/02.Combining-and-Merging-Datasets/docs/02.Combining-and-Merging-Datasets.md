# Combining and Merging Datasets in Pandas

Pandas provides two foundational methods to combine datasets: concatenation and relational merging.

---

## `pd.concat()` vs `pd.merge()`

| Operation | Function | Axis / Direction | Matching Criterion | Typical Use Case |
|---|---|---|---|---|
| **Vertical Stacking** | `pd.concat(axis=0)` | Vertical (rows) | By column names | Appending new records over time (e.g. daily logs, semester intakes) |
| **Horizontal Stacking** | `pd.concat(axis=1)` | Horizontal (columns) | By row index labels | Appending feature matrices side-by-side |
| **Relational Merge** | `pd.merge(on='Key')` | Relational join | By common key values | Joining normalized database tables (e.g. Customers & Orders) |

---

## Tracking Lineage with `indicator=True`
When debugging data integrations, pass `indicator=True` to inspect where rows came from:
```python
merged = pd.merge(df1, df2, on="StudentID", how="outer", indicator=True)
print(merged["_merge"].value_counts())
# Output:
# both          4
# left_only     1
# right_only    1
```
