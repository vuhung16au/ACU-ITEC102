# Stack and Unstack Operations in Pandas

In hierarchical (multi-level) datasets, `.stack()` and `.unstack()` reshape the DataFrame by rotating levels between row and column indices.

---

## 1. Visual Mechanics

```text
               Unstack (Row -> Column)
          +----------------------------->
   Rows                                    Columns
 (Taller)                                 (Wider)
          <-----------------------------+
                Stack (Column -> Row)
```

- **`.stack()`**: "Packs" column headers down into the row index, creating taller, narrower DataFrames.
- **`.unstack()`**: "Unpacks" row index levels up into column headers, creating wider DataFrames.

---

## 2. Level Targeting

Both methods default to targeting the innermost level (`level=-1`), but any level can be targeted by index or label:

```python
# Stack the outermost column level into rows
df_stacked = df.stack(level=0)

# Unstack a specific row level by name into columns
df_unstacked = df.unstack(level='Campus')
```

---

## 3. Incomplete Combinations & `fill_value`

When unstacking creates coordinates for which no data exists in the original DataFrame, `NaN` is inserted. Use `fill_value` to replace these missing values with an appropriate default (such as `0` for counts or revenue):

```python
df.unstack(fill_value=0)
```
