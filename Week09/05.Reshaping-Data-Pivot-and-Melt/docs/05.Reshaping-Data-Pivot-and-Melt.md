# Reshaping Data: Pivot and Melt in Pandas

Data reshaping transforms the structural arrangement of rows and columns without losing underlying values.

---

## 1. Wide vs. Long Data

### Wide Format
- Each measured variable or time point has its own column.
- Convenient for human visual inspection and manual spreadsheet entry.
- Example: `StudentID | Name | Quiz1 | Quiz2 | Exam`

### Long Format (Tidy Data)
- Each row represents a single observation; each variable has its own column.
- Standard format required by machine learning pipelines, relational databases, and plotting libraries (e.g. Seaborn, Plotly).
- Example: `StudentID | Assessment | Score`

---

## 2. Wide to Long: `pd.melt()`

```python
df_long = pd.melt(
    df_wide,
    id_vars=['student_id', 'name'],
    value_vars=['assignment_1', 'assignment_2', 'final_exam'],
    var_name='assessment',
    value_name='score'
)
```

---

## 3. Long to Wide: `DataFrame.pivot()`

```python
df_wide = df_long.pivot(
    index='student_id',
    columns='assessment',
    values='score'
).reset_index()
```
*Note*: Requires that each `(index, columns)` pair is distinct.

---

## 4. Aggregating Duplicates: `DataFrame.pivot_table()`

When multiple rows share the same index-column coordinate, `.pivot_table()` applies an aggregation function (`aggfunc='mean'`, `'sum'`, etc.):

```python
summary = pd.pivot_table(
    df,
    values='mark',
    index='campus',
    columns='unit',
    aggfunc='mean',
    fill_value=0,
    margins=True,
    margins_name='Average'
)
```
