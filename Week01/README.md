# ITEC102 - Week 01 — Python Foundations & Development Environments

This week is a refresher on Python fundamentals and an introduction to three popular Python development environments. Work through the sub-folders in order.

---

## Sub-folders

### [`00.w3schools/`](./00.w3schools/README.md) — Python Refresher

A guided refresher on core Python concepts using [W3Schools](https://www.w3schools.com/python/). Topics covered: running Hello World, Python statements, variables, numbers, operators, and lists.

### [`01.Google-Colab/`](./01.Google-Colab/README.md) — Google Colab

Learn to use [Google Colab](https://colab.research.google.com/) for cloud-based Python development. Covers environment setup, running the official "Welcome to Colab" notebook, and an optional Gemini AI integration exercise.

### [`02.VSCode+Jupyter/`](./02.VSCode+Jupyter/README.md) — VS Code & Jupyter Notebook

Set up [VS Code](https://code.visualstudio.com/) with the Jupyter extension for local notebook development. Includes keyboard shortcuts and a recommended project folder structure.

### [`03.docker+Jupyter/`](./03.docker+Jupyter/README.md) — Docker & Jupyter Notebook

Run a Jupyter Notebook server inside a Docker container — no local Python installation needed. Includes a ready-to-use `docker-compose.yml` and a sample `hello_itec102.ipynb` notebook.

---

## Verification

After completing all four sections, you should be able to run the following snippet in **any** of the three environments (Colab, VS Code, or Docker):

```python
print("Hello ITEC102")
```
