# ITEC102 - Week 01 — Python Development with Google Colab

[Google Colab](https://colab.research.google.com/) is a free, cloud-based Jupyter Notebook environment that requires no local setup. It is a great choice for learning Python, running data science experiments, and collaborating with others.

---

## Topics

### 1. Setup Google Colab (Revisit Week 00)

If you haven't set up Google Colab yet, revisit the Week 00 guide:

- 🔗 [Week 00 — Google Colab Setup](https://github.com/vuhung16au/ACU-ITEC102/blob/main/Week00/06.Google-Colab.md)

**Quick start checklist:**
- [ ] You have a Google account
- [ ] You can navigate to [colab.research.google.com](https://colab.research.google.com/)
- [ ] You can create a new notebook (`New Notebook` button or `Upload Notebook` if you have one)
- [ ] You can connect to a runtime (click **Connect** in the top-right corner)

### 2. Read and Run the "Welcome to Colab" Notebook

Google provides an official introduction notebook to help you get familiar with the environment.

- 🔗 [Welcome to Colab](https://colab.research.google.com/notebooks/intro.ipynb)

**What to do:**
1. Open the link above
2. Read through the notebook
3. Run each cell by clicking the ▶ play button or pressing `Shift + Enter`
4. Explore the sections on:
   - Writing and running code
   - Adding text (Markdown) cells
   - Connecting to Google Drive
   - Using built-in libraries
