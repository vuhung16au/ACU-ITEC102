# Enrichment Projects

## 1. Overview
Welcome to the Enrichment folder! This folder contains supplementary, advanced projects that go beyond the core curriculum of ITEC102. Please note that **these projects are enrichment only and are not mandatory** for completing the unit.

## 2. Why?
Technology evolves rapidly. These projects are designed to help you:
- Stay up-to-date with current industry tech stacks.
- Build impressive, real-world portfolio projects.
- Prepare for technical interview questions and scenarios.

## 3. FAQ
- **Is this out of scope for the ITEC102 unit?** 
  Yes, these topics are beyond the scope of the regular coursework.
- **Why do I need this?** 
  To bridge the gap between academic learning and industry expectations, giving you a competitive edge.
- **Who needs to do this?** 
  Students who want to get ahead, challenge themselves, and deepen their practical programming skills.
- **Will more projects be added?** 
  Yes. More projects will be added as we proceed with the unit and based on student requests.

## 4. Structure of this folder
Each enrichment project is contained within its own subfolder, featuring its own documentation, source code, and resources.

## 5. How to learn?
To get the most out of these projects:
1. **Read the Docs:** Start by reading the `README.md` and `QUICKSTART.md` files in each project folder.
2. **Explore:** Review any materials in the `docs/` folder for deeper context.
3. **Get Hands-on:** Read the code, run it, modify it, and try building upon it yourself!

## 6. Conclusions
These enrichment projects are your sandbox for advanced learning. Dive in, experiment, break things, and build something you're proud to show off!
