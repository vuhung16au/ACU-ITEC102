# Data Sources

The main data source for this project is the **Road Vehicles Australia** dataset from `data.gov.au`.

- **Dataset**: Road Vehicles Australia - January 2025
- **URL**: [Data.gov.au Resource Link](https://data.gov.au/data/dataset/road-vehicles-australia-january-2025/resource/dd3847ae-9c18-4750-9d35-3c5b7d03c49a)

## How to Fetch the Data

You can fetch the data in two ways:

1. **Direct Download**: Download the dataset directly from the URL provided above.
2. **Using CKAN API**: You can use the `ckanapi` Python package to query and fetch the dataset programmatically directly from the `data.gov.au` data portal. This allows for automated data pipelines without manual downloading.
