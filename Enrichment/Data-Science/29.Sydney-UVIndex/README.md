# Sydney UV Index Visualizer

This project is an interactive Streamlit web application that fetches, processes, and visualizes Sydney UV Index time-series geospatial data. The core educational objective is to showcase `matplotlib` for data visualization inside a modern web app.

## Learning Objectives
- Understanding time-series data visualization using `matplotlib`.
- Creating plots and histograms from `pandas` DataFrames.
- Integrating Matplotlib figures into a `streamlit` dashboard.
- Handling online CSV data with local fallbacks.

## Visualizations
The app features:
- A map showing the data collection location.
- Key metrics summarizing the UV Index data.
- A time-series timeline of the UV Index highlighting extreme levels.
- A histogram showing the frequency distribution of UV Index values.
