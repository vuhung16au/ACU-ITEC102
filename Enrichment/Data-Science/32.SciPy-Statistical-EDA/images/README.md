# Images Directory

This directory stores generated Seaborn visualisations and screenshots from the SciPy Statistical EDA pipeline:

- `01_weight_change_by_sex.png`: Density histogram, KDE, and boxplot comparing 12-week weight change between male and female participants.
- `02_random_splits_neg_log10_p.png`: Histogram of `-log10(p-value)` across 1,000 random 50/50 dataset splits with the `p = 0.05` significance threshold.
- `03_weight_height_ratio_by_sex.png`: Violin plot comparing `weight_height_ratio` (`kg/cm`) across sex groups.
- `04_correlation_matrix_heatmap.png`: Annotated Pearson correlation matrix heatmap alongside a Seaborn regression scatter plot of weekly exercise hours versus weight change.
