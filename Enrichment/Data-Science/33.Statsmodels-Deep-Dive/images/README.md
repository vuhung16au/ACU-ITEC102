# Images Directory

Stores diagnostic figures generated by `main.py`:

- `01_qqplot_and_mean_ci.png`: `sm.qqplot` normality check on `weight_change` alongside group mean 95% confidence intervals from `DescrStatsW` and `CompareMeans`.
- `02_ols_and_multiple_testing.png`: Simple OLS regression (`weight_change ~ weight2`) alongside false-positive counts before and after `multipletests` (`fdr_bh` and `bonferroni`) across 1,000 random splits.
