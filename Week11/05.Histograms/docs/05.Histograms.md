# Histograms in Matplotlib

Histograms convert continuous numeric variables into frequency counts across discrete bin intervals.

---

## 1. Syntax

```python
counts, bins, patches = ax.hist(
    data,
    bins=15,             # Or an explicit list of edges: [0, 50, 65, 75, 85, 100]
    color='#1f77b4',
    edgecolor='black',
    alpha=0.75
)
```

---

## 2. Reading Skewness

- **Symmetric (Normal)**: Bell-shaped; $\text{Mean} \approx \text{Median}$.
- **Right-Skewed (Positive Skew)**: Long right tail of extreme values (e.g. house prices, executive salaries); $\text{Mean} > \text{Median}$.
- **Left-Skewed (Negative Skew)**: Long left tail of low scores (e.g. easy university exams with a few failing students); $\text{Mean} < \text{Median}$.

---

## 3. Reference Lines

```python
ax.axvline(np.mean(data), color='crimson', linestyle='--', label='Mean')
ax.axvline(np.median(data), color='gold', linestyle='-', label='Median')
```
