# Histograms

This module covers continuous variable frequency distributions using Matplotlib, including bin selection, explicit grade boundary intervals, overlaying mean and median reference lines, and diagnosing skewness.

---

## Learning Objectives
- Differentiate between histograms (continuous data binned into intervals) and bar charts (discrete categories).
- Control bin sizing using integer counts (`bins=15`) and explicit bin boundary lists.
- Add central tendency vertical reference lines (`ax.axvline()`) for Mean and Median.
- Diagnose skewness (right-skewed vs left-skewed) and multi-modal distributions.
