# Bar Charts

This module covers discrete category comparison using Matplotlib, including vertical bar charts, horizontal bar charts for long titles, grouped (clustered) bar charts, stacked bar charts, and direct value annotations using `ax.bar_label()`.

---

## Learning Objectives
- Compare values across discrete cohorts using vertical (`ax.bar()`) and horizontal (`ax.barh()`) bar charts.
- Annotate exact values directly onto bars using `ax.bar_label()`.
- Construct clustered bar charts comparing multiple subgroups using bar-width coordinate offsets.
- Build stacked bar charts using the `bottom=` argument to depict cumulative totals and sub-cohort composition.
