# Bar Charts in Matplotlib

Bar charts represent discrete categorical quantities through bar lengths or heights.

---

## 1. Vertical vs. Horizontal

- **Vertical (`ax.bar`)**: Best when categories are few ($\le 7$) and category labels are short (e.g. abbreviations or years).
- **Horizontal (`ax.barh`)**: Essential when category labels are long phrases (e.g. Faculty names, job titles) to prevent diagonal or vertical text truncation.

---

## 2. Clustered (Grouped) Bar Mechanics

To display side-by-side comparisons:
```python
x = np.arange(len(categories))
width = 0.35

ax.bar(x - width/2, series1, width=width, label='Group A')
ax.bar(x + width/2, series2, width=width, label='Group B')
ax.set_xticks(x, categories)
```

---

## 3. Stacked Bars

To display aggregate totals and composition:
```python
ax.bar(categories, base_series, label='Base')
ax.bar(categories, top_series, bottom=base_series, label='Top')
```

---

## 4. Direct Labelling

Avoid requiring readers to trace bar heights back to the y-axis:
```python
bars = ax.bar(categories, values)
ax.bar_label(bars, padding=3)
```
