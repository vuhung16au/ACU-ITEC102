# Pie and Donut Charts in Matplotlib

Pie charts encode proportional shares of a whole as circular angular sectors.

---

## 1. Parameters

```python
ax.pie(
    sizes,
    labels=labels,
    autopct='%1.1f%%',     # String format for slice percentages
    startangle=90,          # Angle at which the first slice starts
    explode=(0, 0.1, 0),    # Offsets slices outward for emphasis
    wedgeprops=dict(width=0.4, edgecolor='white')  # Creates donut ring
)
```

---

## 2. When to Use (and When NOT to Use)

### When Pie Charts Work
- Exactly 2 to 4 distinct categories.
- One category overwhelmingly dominates, or you want to highlight a 50/50 split.

### When to Avoid Pie Charts
- More than 5 categories (results in clutter and illegible labels).
- Categories have very similar shares (e.g. 18% vs 20% vs 22%), which humans cannot differentiate visually.
- Data does not sum to 100% (e.g. multi-select survey questions).
- **Default Recommendation**: Use a sorted horizontal bar chart instead.
