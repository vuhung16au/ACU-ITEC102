# Customising and Styling in Matplotlib

Transform basic charts into presentation- and publication-ready visual assets.

---

## 1. Global Themes

Apply a consistent aesthetic across all figures in your analysis:
```python
plt.style.use('seaborn-v0_8-whitegrid')
```

---

## 2. Multi-Panel Dashboards

Assemble multiple related views on a shared canvas:
```python
fig, axes = plt.subplots(2, 2, figsize=(12, 9))
fig.suptitle('Executive Dashboard', fontsize=15, fontweight='bold')

# Access subplots by grid coordinate
axes[0, 0].bar(...)
axes[0, 1].scatter(...)
axes[1, 0].plot(...)
axes[1, 1].hist(...)

plt.tight_layout()
```

---

## 3. High-Impact Annotations

```python
ax.annotate(
    'Key Milestone',
    xy=(target_x, target_y),
    xytext=(text_x, text_y),
    arrowprops=dict(facecolor='black', arrowstyle='->', lw=1.5),
    fontweight='bold'
)
```

---

## 4. Export Settings

```python
fig.savefig('figure.png', dpi=300, bbox_inches='tight')
```
- `dpi=300`: High-density resolution suitable for print and high-res screens.
- `bbox_inches='tight'`: Trims whitespace padding automatically around axis labels.
