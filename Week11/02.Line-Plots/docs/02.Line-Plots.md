# Line Plots in Matplotlib

Line plots connect discrete data points with straight lines, making them the industry standard for time-series and continuous trend analysis.

---

## 1. Syntax and Styling Parameters

```python
ax.plot(
    x, y,
    color='#1f77b4',       # Line color (hex or named)
    linestyle='--',        # Line style: '-', '--', '-.', ':'
    linewidth=2.0,         # Stroke thickness
    marker='o',            # Point marker: 'o', 's', '^', 'D'
    markersize=6,          # Size of markers
    label='Series Label'   # Label for legend
)
```

---

## 2. Best Practices for Line Plots

1. **Ordering Matters**: Ensure x-axis values are sorted chronologically or monotonically.
2. **Avoid Spaghetti Charts**: Limit lines on a single chart to 3–5 series; use subplots or faceting if you have more.
3. **Accessibility**: Combine line color with distinct markers and line styles so viewers with color vision deficiencies can differentiate series.
4. **Direct Annotations**: For critical inflection points, use `ax.annotate()` to highlight values directly on the curve.
