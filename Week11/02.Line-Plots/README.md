# Line Plots

This module covers creating continuous trend charts and time-series visualisations in Matplotlib, including multi-line comparisons, line styles, markers, gridlines, legends, and peak annotations.

---

## Learning Objectives
- Visualise continuous time-series data using `ax.plot()`.
- Compare multiple series on the same Axes with distinct styling (`color`, `linestyle`, `marker`).
- Format axis labels, plot titles, gridlines, and legends (`ax.legend(ncol=...)`).
- Annotate specific data points and peaks using `ax.annotate()`.

---
