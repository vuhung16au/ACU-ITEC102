# Why Visualisation Matters

Summary tables (mean, variance, correlation) summarize datasets into compact numbers, but they discard geometry and spatial relationships.

---

## 1. Anscombe's Quartet (1973)

Francis Anscombe formulated four distinct datasets:

| Property | Value Across All 4 Datasets |
| :--- | :--- |
| Mean of $x$ | $9.0$ |
| Variance of $x$ | $11.0$ |
| Mean of $y$ | $7.50$ |
| Variance of $y$ | $4.12$ |
| Correlation ($r$) | $0.816$ |
| Linear Regression Line | $y = 3.00 + 0.50x$ |

Yet, plotting them reveals:
1. **Dataset I**: Standard linear relationship with random noise.
2. **Dataset II**: A perfect parabola where linear models fail completely.
3. **Dataset III**: A strict line where one vertical outlier skews the slope.
4. **Dataset IV**: A vertical cluster where a single high-leverage point creates the correlation artificially.

## 2. Matplotlib Architecture: Figure vs. Axes

```text
+-----------------------------------------------------------+
| Figure (The complete canvas/window)                       |
|                                                           |
|   +---------------------------+   +-------------------+   |
|   | Axes 1 (Subplot 1)        |   | Axes 2            |   |
|   | - Title                   |   |                   |   |
|   | - X-Axis & Y-Axis         |   |                   |   |
|   | - Data points & lines     |   |                   |   |
|   +---------------------------+   +-------------------+   |
+-----------------------------------------------------------+
```

Always prefer the **Object-Oriented API**:
```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(x, y)
ax.set_title("Title")
```
