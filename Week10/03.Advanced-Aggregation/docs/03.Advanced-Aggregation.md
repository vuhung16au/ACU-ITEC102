# Advanced Aggregation in Pandas

Standard `.groupby()` operations apply one aggregation across all columns. Advanced aggregation allows granular control over which functions apply to which columns.

---

## 1. Multiple Metrics on Single Columns

```python
df.groupby('faculty')['research_grant_kaud'].agg(['count', 'mean', 'std', 'min', 'max'])
```

---

## 2. Column-Specific Dictionary Mapping

```python
df.groupby('campus').agg({
    'research_grant_kaud': ['sum', 'mean'],
    'publications': 'sum',
    'satisfaction_pct': 'mean'
})
```

---

## 3. Modern Named Aggregations (Pandas 0.25+)

Avoids complex MultiIndex column tuples and renames outputs cleanly in a single pass:

```python
clean_df = df.groupby('campus').agg(
    total_projects=('research_grant_kaud', 'count'),
    total_grants=('research_grant_kaud', 'sum'),
    avg_grant=('research_grant_kaud', 'mean'),
    avg_satisfaction=('satisfaction_pct', 'mean')
)
```
Each tuple takes `(column_name, aggregation_function)`.
