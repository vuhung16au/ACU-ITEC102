# Custom Aggregation Functions in Pandas

When standard descriptive statistics (`mean`, `std`, `min`, `max`) are insufficient, you can pass custom Python callables to `.agg()`.

---

## 1. Structure of a Custom Aggregator

A valid custom aggregator:
1. Takes a `pd.Series` of values for each group.
2. Returns a single scalar (`float`, `int`, `str`, `bool`).

```python
def pass_rate_pct(s: pd.Series) -> float:
    cleaned = s.dropna()
    return (cleaned >= 50).mean() * 100.0 if not cleaned.empty else 0.0
```

---

## 2. Applying with Custom Column Labels

Pass a list of `('New_Column_Name', callable)` tuples:

```python
df.groupby('unit')['mark'].agg([
    ('Student_Count', 'count'),
    ('Average', 'mean'),
    ('Pass_Rate', pass_rate_pct)
])
```

---

## 3. Inline Lambdas

For simple thresholding or proportions:

```python
df.groupby('unit')['mark'].agg([
    ('Distinction_pct', lambda s: (s >= 75).mean() * 100.0)
])
```
