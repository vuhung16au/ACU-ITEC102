# Adding Margins and Totals in Pandas

Summary reports prepared for presentations or stakeholders require row totals, column totals, and grand totals.

---

## 1. Enabling Margins in Pivot Tables

```python
table = pd.pivot_table(
    df,
    values='enrolments',
    index='campus',
    columns='residency',
    aggfunc='sum',
    margins=True,
    margins_name='Grand Total'
)
```

---

## 2. Mathematical Nuance of Margins

When `aggfunc='mean'`, the bottom-right grand total is **not** the average of the column or row means:
- Averaging group averages ignores group sizes (e.g. Sydney having 1000 students and Brisbane having 50 students).
- Pandas margins compute the aggregation function directly over the **entire underlying unsegmented dataset**.

---

## 3. Normalised Frequency Tables with `pd.crosstab()`

```python
# Row percentages (each row sums to 100%)
pct_table = pd.crosstab(
    df['campus'],
    df['faculty'],
    normalize='index',
    margins=True
) * 100
```
