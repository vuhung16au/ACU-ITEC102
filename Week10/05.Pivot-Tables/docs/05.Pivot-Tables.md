# Pivot Tables in Pandas

While `.groupby()` groups data along a single dimension or produces hierarchical rows, `pd.pivot_table()` is designed for two-dimensional grid cross-tabulation.

---

## 1. Syntax

```python
table = pd.pivot_table(
    df,
    values='salary_kaud',
    index='state',
    columns='specialisation',
    aggfunc='mean',
    fill_value=0
)
```

---

## 2. When to Use GroupBy vs Pivot Table

| Feature | `df.groupby()` | `pd.pivot_table()` |
| :--- | :--- | :--- |
| **Output Shape** | Flat or hierarchical Series / DataFrame | Two-dimensional matrix / grid |
| **Primary Use** | Data pipelines, transformations, modeling | Executive reporting, heatmaps, cross-tabulation |
| **Default Aggregation** | None (must call `.mean()`, `.sum()`, etc.) | `'mean'` |
| **Missing Combinations** | Rows simply omitted | Populated with `NaN` or `fill_value` |
