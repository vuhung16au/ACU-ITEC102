# Multi-Level Grouping in Pandas

Multi-level grouping segments data across multiple categorical dimensions simultaneously.

---

## 1. Syntax and MultiIndex Structure

```python
grouped = df.groupby(['campus', 'faculty'])[['enrolments', 'funding_kaud']].sum()
```

The resulting object is a DataFrame whose Index has multiple hierarchical levels:
- Level 0: `campus`
- Level 1: `faculty`

---

## 2. Slicing Hierarchical Rows

```python
# Slice all rows for North Sydney
grouped.loc['North Sydney']

# Slice a specific composite key pair
grouped.loc[('Melbourne', 'Health Sciences')]
```

---

## 3. Rotating Dimensions: `.unstack()`

To compare categories across columns rather than stacked rows:

```python
enrolment_matrix = df.groupby(['campus', 'faculty'])['enrolments'].sum().unstack(fill_value=0)
```

---

## 4. Within-Group Normalisation: `.transform()`

To calculate what proportion of each group's total belongs to each subgroup without flattening:

```python
campus_totals = df.groupby('campus')['enrolments'].transform('sum')
df['share_pct'] = (df['enrolments'] / campus_totals) * 100
```
