# GroupBy Basics in Pandas

The **Split-Apply-Combine** paradigm is the fundamental framework for group-level data manipulation.

---

## 1. The Split-Apply-Combine Workflow

```text
       Original Table                  Split into Groups                  Apply (.mean())             Combine
+---------+--------+-------+         +-----------------------+        +---------------------+     +-----------------+
| Campus  | Course | Mark  |         | North Sydney (2 rows) |  --->  | mean(Mark) = 85.75  |     | Campus     Mark |
|---------|--------|-------|  --->   | Melbourne    (2 rows) |  --->  | mean(Mark) = 80.00  | --> | Brisbane   69.7 |
| Sydney  | IT     | 82.5  |         | Brisbane     (2 rows) |  --->  | mean(Mark) = 69.75  |     | Melbourne  80.0 |
| Melb    | Nurse  | 76.0  |         +-----------------------+        +---------------------+     | Sydney     85.8 |
+---------+--------+-------+                                                                      +-----------------+
```

---

## 2. Inspecting GroupBy Objects

```python
grouped = df.groupby('campus')

# Total number of groups
print(grouped.ngroups)

# Count of rows per group
print(grouped.size())

# Retrieve one specific group
melbourne_cohort = grouped.get_group('Melbourne')
```

---

## 3. Controlling Indexing with `as_index`

- `as_index=True` (default): Grouping keys become the Index of the result.
- `as_index=False`: Grouping keys remain regular DataFrame columns, convenient for plotting or relational merges.

```python
df.groupby('campus', as_index=False)['wam'].mean()
```
