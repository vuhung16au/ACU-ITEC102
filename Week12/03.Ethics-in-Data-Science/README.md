# Ethics in Data Science: Algorithmic Governance & Responsible AI

This module introduces students to the ethical dimensions of data science, focusing on the 8 Australian AI Ethics Principles, Australian Privacy Principles (APPs), and algorithmic accountability.

---

## Learning Objectives
- Understand the 8 Australian AI Ethics Principles and their practical application in software and data pipelines.
- Audit Automated Decision-Making (ADM) models for indirect bias and socio-demographic proxy discrimination.
- Design Human-in-the-Loop (HITL) escalation pathways for high-stakes decision points.
- Implement an automated Ethical Impact Assessment (EIA) scoring rubric.

---

## Folder Structure
- `docs/`: Conceptual documentation on AI ethics frameworks and statutory privacy requirements.
- `notebooks/`:
  - `01_03.Ethics-in-Data-Science.ipynb`: Interactive Jupyter notebook auditing algorithmic decisions and running EIA evaluations.
- `src/`:
  - `EthicsinDataScience.py`: Standalone Python script running the complete ethics audit pipeline.
- `QUICKSTART.md`: Step-by-step instructions to run scripts and launch notebooks.
- `Makefile`: Convenience commands (`make run`, `make test`, `make clean`).
