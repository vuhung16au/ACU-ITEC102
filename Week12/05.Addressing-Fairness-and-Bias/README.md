# Addressing Fairness and Bias in Data Science

This module introduces students to the mathematics, ethics, and legal benchmarks for auditing and mitigating algorithmic bias in data science pipelines.

---

## Learning Objectives
- Differentiate between Historical Bias, Representation Bias, and Proxy Bias.
- Calculate group acceptance rates and evaluate Demographic Parity.
- Apply the **80% (Four-Fifths) Adverse Impact Rule** and calculate the **Disparate Impact Ratio (DIR)**.
- Implement post-processing threshold adjustments to eliminate unfair disadvantage.

---

## Folder Structure
- `docs/`: Conceptual documentation on fairness metrics, the 80% rule, and mitigation paradigms.
- `notebooks/`:
  - `01_05.Addressing-Fairness-and-Bias.ipynb`: Interactive Jupyter notebook simulating biased scholarship admissions and threshold calibrations.
- `src/`:
  - `AddressingFairnessandBias.py`: Complete executable Python script running fairness audits and mitigation algorithms.
- `QUICKSTART.md`: Setup and execution guide.
- `Makefile`: Convenience commands (`make run`, `make test`, `make clean`).
