# Real-World Data Wrangling: Best Practices & Techniques

In real-world data science, raw datasets rarely arrive in clean, structured formats. Human data entry errors, disparate system exports, and differing regional conventions introduce defects that must be systematically audited and corrected.

---

## 1. The Anatomy of Real-World Data Defects

| Defect Category | Typical Manifestation | Pandas Remedy |
| :--- | :--- | :--- |
| **Whitespace Padding** | `"  Liam NGUYEN  "`, `" Melbourne "` | `df['col'].str.strip()` |
| **Inconsistent Casing** | `"SYD"`, `"sydney"`, `"syd"` | `df['col'].str.lower().map(lookup)` |
| **Formatted Numbers** | `"$1,500.00 AUD"`, `" $2,250.50 "` | `df['col'].str.replace(r'[$,AUD\s]', '', regex=True).astype(float)` |
| **Mixed Date Formats** | `"2026-01-15"`, `"18/01/2026"`, `"2026.02.01"` | `pd.to_datetime(df['col'], format='mixed')` |
| **Missing Values** | `None`, `np.nan`, `"N/A"`, blank strings | `df['col'].fillna(default_value)` |
| **Relational Mismatches** | Keys separated across lookup tables | `pd.merge(df, lookup, left_on='...', right_on='...', how='left')` |

---

## 2. Defensive Wrangling Rules

1. **Always Work on Copies**: Avoid mutating raw inputs directly; use `df.copy()` at the start of pipeline functions.
2. **Audit Before and After**: Check `df.info()`, `df.isna().sum()`, and `df.dtypes` before applying transformations and immediately after.
3. **Handle Exceptions Gracefully**: When parsing dates or numbers from third-party systems, specify fallback behaviours (e.g. `errors='coerce'`) to flag unparseable rows rather than crashing the pipeline.
4. **Preserve Relational Integrity**: Use `how='left'` when joining secondary lookup tables so primary records are not silently dropped if lookup keys are missing.
