# The 5-Step Exploratory Data Analysis (EDA) Framework

Exploratory Data Analysis (pioneered by John Tukey in 1977) emphasizes visual and statistical exploration of data before making modeling assumptions.

## 2. Detecting Outliers with Tukey's Fences

Given sample quartiles $Q_1$ (25th percentile) and $Q_3$ (75th percentile):

$$\text{IQR} = Q_3 - Q_1$$

$$\text{Lower Fence} = Q_1 - 1.5 \times \text{IQR}$$
$$\text{Upper Fence} = Q_3 + 1.5 \times \text{IQR}$$

Any observation $x < \text{Lower Fence}$ or $x > \text{Upper Fence}$ is classified as a mild outlier. Points beyond $3 \times \text{IQR}$ are considered extreme outliers.

---

## 3. Parametric vs. Non-Parametric Metrics

- **Symmetric Distributions**: Mean and Standard Deviation are reliable measures of location and spread.
- **Skewed Distributions / Datasets with Outliers**: Median and Interquartile Range (IQR) provide robust, non-parametric measures that resist distortion from extreme observations.
